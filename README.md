# 大筛选请求的可重发领取与传输确认

供应商的追溯查询要提交几万条批次号，原来的领取器一次把请求体放进内存，查大客户就撑爆；直接改成流之后，又在网关重定向时只发出去后半截。这里保存现有资料预览工具和本地供方模拟服务，便于离线开发和复查领取行为。

## 当前能力

`npm run demo` 从实际本地资料源获取一次预览，然后把只读追溯查询纳入领取流程完整执行一次：查询体流式暂存落盘（几万条批次号不一次进入内存）、携带 `Expect: 100-continue` 发送、按网关指令处理继续/拒绝/跳转、与源端记录对照方法、摘要和字节，并把每次尝试的审计写入 `var/captures.json`。暂存区默认在 `var/staging`（`STAGE_PATH` 可改），进程重启后只有「清单 + 内容 + 摘要校验」齐全的暂存体可被安全领取，残缺部分会被清除而不是复用。

`src/domain.mjs` 保留已有领域预览函数；`src/store.mjs` 提供带完整性校验的单进程顺序接收文件，不是跨进程事务数据库。

## 运行

固定 Node.js 22.22.1，不依赖外部服务。所有 HTTP 资料源由进程在回环随机端口启动并关闭。

```sh
npm ci
npm run build
npm test
npm run demo
```

推荐使用固定镜像构建，首次构建会安装锁文件中的依赖；运行时不需联网。

```sh
docker build -t plant-query-body .
docker run --rm --network none --ipc=host plant-query-body npm test
docker run --rm --network none --ipc=host plant-query-body npm run demo
```

开发时 `npm start` 打印本地源地址；设置 `PORT` 可指定监听端口，未设置时自动分配回环端口。浏览器页面或 HTTP 接口可直接查看。`CAPTURE_PATH` 可改变接收文件路径。重复运行预览追加记录；删除 `var` 可从空接收状态开始。

## 模块

- `src/source.mjs`：该业务的本地资料源与演示控制，独立于待扩展的接收行为。
- `src/domain.mjs`：现有原始资料预览和领域数据结构；`encodeQueryChunks` 是与一次性编码字节一致的流式编码器。
- `src/staging.mjs`：查询体暂存区。流式落盘并记录摘要；取消或崩溃不留残缺；`sweep` 在重启后报告可安全领取的暂存体并清除不可领取部分。
- `src/transfer.mjs`：单次传输尝试。等待网关继续指令后才发送，统计实际发送字节，支持操作者中止。
- `src/claim.mjs`：领取编排。保持方法与查询体的授权内跳转、凭据不越权、按查询能力与传输事实决定重发、回执对照、取消清理，全程输出审计。
- `src/preview.mjs`：读取、预览、领取及持久化的一次运行入口。
- `fixtures/source.json` 与 `fixtures/controls.json`：本地供方资料及可切换情形。
- `docs/source.md`：接口和来源约定。
- `test`：现有预览、源端特殊情形、接收文件完整性测试，以及领取流程的网关时序测试。

## 业务核对

以下情况已由 `test/claim.test.mjs` 与 `test/staging.test.mjs` 在本地网关下独立观察（网关分别控制响应发生在发送前、发送中、发送后）：

- 发送前拒绝接收：417 到达时查询体零字节发出，且明确拒绝不重发。
- 保持方法的批准跳转：307 转到同一授权范围内另一入口时，保持 POST 与同一完整查询体重发，两次尝试摘要一致。
- 未批准地址不传递凭据：跳转目标不在授权范围时停止，凭据与查询体都不发往该地址；要求改用 GET 的跳转不被擅自接受。
- 发送中取消清理：操作者取消时传输中止、暂存资源释放，重启后无可领取的残缺查询。
- 重启后残缺暂存体不可发送：只有校验完整的暂存体可领取；重试耗尽的暂存体保留，重启后凭同一摘要完成领取。

源端模拟器只负责制造边界，接收器的核对由上述模块与测试完成。

## 短时操作演示

从空 `var` 运行 `npm run demo`，展示本次真实读取、暂存、领取结果（状态、摘要、字节、未完成原因、可再领取标识）、暂存区清理情况与源端记录对照；再运行 `npm test` 查看本地源边界、接收文件检查与领取流程的网关时序用例。固定环境中的这两步应在 90 秒内完成。演示每次真实执行领取流程并打印本次审计要点，不回放旧日志，不以源端控制操作代替接收结果。
