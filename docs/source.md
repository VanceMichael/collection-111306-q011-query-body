# 本地资料源约定

POST /query 是只读查询。normal 计算实际收到字节摘要；reject 在 Expect:100-continue 前返回 417；redirect 返回 307 到 /query-final；cut 读取首块后关闭连接。GET /api/requests 查看实际方法、摘要及字节。源只允许回环目的地，不需要真实凭据。

## 通用控制

`GET /api/snapshot` 查看当前原始源状态；`POST /api/action` 接收 JSON 对象 `{"action":"动作名"}`。可用动作：reset、reject、redirect、cut。控制只改变模拟源，不代表接收器已经处理了变化。

所有资料均由本项目构造，包含的机构、设备、会话和文件仅供本地使用，不访问真实账号。浏览器操作应通过正常可见界面；测试用源控制接口不是业务采集捷径。

## 来源证据

源端请求记录只用于核查服务行为，接收器自身的审计、状态和输出需由扩展功能负责。源端重启会恢复默认资料，但本地接收文件不会自动清空。
